# Task 10

This is a Node.js project that uses the OpenAI API.

## Setup

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Set up environment variables:**

    Create a `.env` file in the root of this directory (`10/`) with the following content:

    ```
    OPENAI_API_KEY="your_openai_api_key"
    ```

    Replace `"your_openai_api_key"` with your actual OpenAI API key.

3.  **Run the script:**
    ```bash
    npm start
    ```
